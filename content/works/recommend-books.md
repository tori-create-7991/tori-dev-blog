## 概要

ChatGPT APIを活用して、ユーザーの入力から興味に基づく書籍を推薦するサイト。Rakuten APIを使用して
書籍情報を取得し、Netlifyでホスティングしている。

## 使用技術

- ChatGPT API による自然言語処理
- Rakuten Books API による書籍情報取得
- Next.js によるフロントエンド開発
